# Dimitrios Tsountos — portfolio

One-page static portfolio site: plain HTML, CSS and a little vanilla JS, no build step.

- `index.html` — all content
- `styles.css` — styles
- `script.js` — sticky header, mobile menu, active nav link, footer year, plus the motion ideas (transaction trace, coverage tabs, decline decoder, chart, slider, marquee)
- `assets/` — logo, favicons, images and the CV PDF

Open `index.html` in a browser to preview, or serve the folder with any static host (e.g. GitHub Pages from the repository root).
